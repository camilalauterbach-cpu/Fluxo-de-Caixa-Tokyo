# Fluxo-de-Caixa-Tokyo

A versão web atual está no [projeto conectado ao Lovable](https://lovable.dev/projects/745ea666-6e03-4ec7-a2fe-90f6d1e3c34f),
com [backend financeiro nativo e banco no Lovable Cloud](https://github.com/camilalauterbach-cpu/pixel-perfect-replica).
Essa versão não depende de um servidor Python público nem de uma conta no Render.
O código Python deste repositório permanece como referência de regras e para a
instalação original, que deve ser preservada.

Uma hospedagem separada do aplicativo Python continua documentada em
[DEPLOY_TOKYO.md](DEPLOY_TOKYO.md) como alternativa opcional.

[Abrir a versão de trabalho do Tokyo](USAR_TOKYO.md), com as instruções de download e primeira abertura.

A versão de trabalho inclui os dados reais em um pacote protegido. A demonstração com dados fictícios continua documentada em [TESTAR_TOKYO.md](TESTAR_TOKYO.md).
