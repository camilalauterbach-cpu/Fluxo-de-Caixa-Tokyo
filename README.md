# Fluxo-de-Caixa-Tokyo

[Publicar o Tokyo na web](https://render.com/deploy?repo=https://github.com/camilalauterbach-cpu/Fluxo-de-Caixa-Tokyo):
configuração pronta para Python, login, SQLite em disco persistente e HTTPS.
O proprietário autoriza os recursos pagos e informa os três campos privados
na tela do Render. Consulte [DEPLOY_TOKYO.md](DEPLOY_TOKYO.md).

A interface também está no [projeto conectado ao Lovable](https://lovable.dev/projects/745ea666-6e03-4ec7-a2fe-90f6d1e3c34f),
no [repositório da interface](https://github.com/camilalauterbach-cpu/pixel-perfect-replica).
Depois de ativar o servidor, o endereço HTTPS dele conecta essa interface
ao mesmo backend, sem transferir o banco ou a chave para o Lovable.

[Abrir a versão de trabalho do Tokyo](USAR_TOKYO.md), com as instruções de download e primeira abertura.

A versão de trabalho inclui os dados reais em um pacote protegido. A demonstração com dados fictícios continua documentada em [TESTAR_TOKYO.md](TESTAR_TOKYO.md).
